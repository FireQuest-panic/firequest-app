How to install

  1. Tap Download FireQuest. On Samsung phones the download opens in Samsung Internet.
  2. When the download is finished, tap Open, then Install. If your phone asks, tap Settings, switch on Allow from this source, and go back.
  3. Open FireQuest and create your own account. Use your own cellphone number: the one this invite was sent to.
  4. Go to Account → Family plan → I have an invite code and enter the code above.
